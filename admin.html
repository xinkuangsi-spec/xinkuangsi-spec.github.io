网站管理后台

修改网站文字内容 → 点发布 → 约1分钟后网站自动更新。当前站点：xinkuangsi-spec.github.io

第一步：连接 GitHub（只需做一次）

  1. 打开 github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens，点 Generate new token。
  2. Token name 随便填（如 site-admin），Expiration 选 90 days 或更长。
  3. Repository access 选 Only select repositories，只勾选 xinkuangsi-spec.github.io。
  4. Permissions 里找到 Contents，设为 Read and write，其余保持默认，点 Generate token。
  5. 把生成的 github_pat_... 粘贴到下面，点"保存并连接"。这个页面关掉后就看不到 token 了，请先复制好。

第二步：编辑内容

发布后 GitHub 会自动重新构建网站，约 1 分钟后生效（偶尔有几分钟缓存延迟）。
管理页本身是公开网址，但没有你的 token 谁也改不了东西；token 只存在你自己的浏览器里。不要把 token 发给任何人。
