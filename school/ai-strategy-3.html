双均线策略回测：复制粘贴就能跑

一句话讲双均线：短期均线向上穿过长期均线叫“金叉”，买入；向下跌破叫“死叉”，卖出。这一课你会跑通一份完整的回测代码——这是量化里程碑式的一步。

广告 ADVERTISEMENT

先说人话：回测就是用历史数据把策略"演"一遍。如果 2020–2024 年按这个规则买卖能赚钱，策略才有继续看的价值；如果历史数据上都赚不到，真钱就更别想了。

下面这份代码用模拟数据（np.random.seed(42) 固定种子，每次跑结果都一样），保证人人能跑通。存为 ma_backtest.py 运行：

import numpy as np
import pandas as pd

np.random.seed(42)  # 固定随机种子：每次跑结果都一样
n = 1000
rets = np.random.normal(0.0005, 0.015, n)   # 模拟日收益率
price = 100 * np.exp(np.cumsum(rets))        # 生成模拟价格
df = pd.DataFrame({"close": price})

fast, slow = 5, 20
df["ma_fast"] = df["close"].rolling(fast).mean()
df["ma_slow"] = df["close"].rolling(slow).mean()

# 金叉持有、死叉空仓；shift(1) 保证用"昨天"的信号做"今天"的决策
df["signal"] = (df["ma_fast"] > df["ma_slow"]).astype(int)
df["position"] = df["signal"].shift(1).fillna(0)

df["ret"] = df["close"].pct_change().fillna(0)
cost = 0.0003                      # 万3：手续费+滑点假设
trades = df["position"].diff().abs().fillna(0)
df["strat_ret"] = df["position"] * df["ret"] - trades * cost
df["equity"] = (1 + df["strat_ret"]).cumprod()

total = df["equity"].iloc[-1] - 1
ann = (1 + total) ** (250 / n) - 1          # 年化（按250个交易日）
max_dd = ((df["equity"] - df["equity"].cummax())
          / df["equity"].cummax()).min()     # 最大回撤
n_trades = int((df["position"].diff() == 1).sum())
win_rate = (df.loc[df["position"] == 1, "ret"] > 0).mean()

print(f"总收益率: {total:.1%}")
print(f"年化收益率: {ann:.1%}")
print(f"最大回撤: {max_dd:.1%}")
print(f"开仓次数: {n_trades}")
print(f"持有日胜率: {win_rate:.1%}")
预期输出（下面是我们真实运行的结果，你跑出来应该一模一样）： 
总收益率: 71.8%
年化收益率: 14.5%
最大回撤: -24.7%
开仓次数: 31
持有日胜率: 52.1%
指标这份结果人话解读
总收益率 71.8%1000 个交易日赚 71.8%看着美，记住这是模拟数据
年化 14.5%平均每年 14.5%和总收益是同一个意思，换成年化方便对比
最大回撤 -24.7%最惨时从高点亏 24.7%最重要的指标：你能不能拿住？亏 1/4 时睡得着吗
开仓 31 次约每月交易 1 次交易频率，频率越高成本吃得越多
持有日胜率 52.1%持有日子里 52% 是涨的刚过一半——趋势策略靠"截断亏损、让利润奔跑"，不是靠高胜率

★换成你的真实数据

把代码前 6 行换成下面两行（用第 2 课下载的 CSV），后面一行不用动：

df = pd.read_csv("pingan_000001.csv")
df = df.rename(columns={"收盘": "close"})  # 列名对齐，后面代码不动

注意：真实数据只有几百行，n = 1000 那几行模拟数据的代码要删掉，年化公式里的 n 改成 len(df)。让 AI 帮你改——这是很好的练习。
